# Бензовозы

Frontend отчёта DBAnalit: React, TypeScript и Vite. Backend находится в
[devicedev/DBAnalit-clean](https://github.com/devicedev/DBAnalit-clean), модуль
`backend/fuel_trucks`.

## Запуск на 243

Для работы сервера достаточно репозитория backend: готовая сборка интерфейса уже
входит в `static/fuel-trucks`. Node.js и этот репозиторий на сервере не нужны.
После обновления backend и запуска `python app.py` существующая кнопка
«Отчёт о бензовозах» открывает `/fuel-trucks/`. Старый адрес
`/agri/fuel-truck-report/view` перенаправляет на новый отчёт.

Доступ к 1С, PostgreSQL и Wialon настраивается только в `.env` backend. Токены,
пароли, `.env`, служебные данные и `node_modules` не публикуются в этом репозитории.

## Разработка

Требуется Node.js 22.12+ или поддерживаемая более новая версия.

```powershell
npm ci
Copy-Item .env.example .env.local
npm run dev
```

В `.env.local` укажите адрес работающего backend, например:

```dotenv
FUEL_TRUCKS_API_TARGET=http://10.90.25.125:5000
```

Откройте `http://10.90.25.125:5179/static/fuel-trucks/` либо адрес своего ПК.
Dev-сервер слушает все интерфейсы на порту 5179. API и переход на главную идут
через proxy; абсолютного адреса сервера в готовой сборке нет.

## Сборка и обновление backend

```powershell
npm run test
npm run build
node scripts/sync-backend.mjs C:\files\projects\DBAnalit-clean
```

Сборка сначала сохраняется в `dist`, затем копируется только в
`static/fuel-trucks` указанного backend. Коммитите изменившийся `index.html` и
новые файлы `assets` в репозиторий backend, чтобы сервер обновлялся через Git.

В отчёте есть период, фильтры хозяйств и источников, детализация выдач 1С и Wialon,
сверка получателей и сопоставления по госномерам с историей действия связей.
Редактирование сопоставлений требует входа через учётную запись DBAnalit.
Excel содержит пять столбцов: дата, получатель 1С, выдано 1С (л),
карточка получателя Wialon, выдано Wialon (л). Подтверждённые расхождения
выделяются цветом; несопоставленные выдачи сохраняются отдельно.


## Выгрузка за год и всё время

«Выгрузить Excel» открывает отдельное окно с общим календарём проекта:
дни, месяцы, кварталы, выбор любого года, произвольный диапазон без ограничения
366 дней и режим «За всё время». Начальные даты берутся из текущего отчёта.
Хозяйства, тип и источники наследуются со страницы на момент запуска.

Используется фоновый API `/api/fuel-trucks/v1/exports`: браузер передаёт только
даты и фильтры, проверяет прогресс и скачивает готовый файл напрямую с сервера.
Закрытие окна и обновление страницы не останавливают подготовку. ID задания
сохраняется в рамках вкладки; готовый файл можно повторно скачать в течение суток.
Скачивание начинается только по нажатию «Скачать Excel»; подготовка и обновление
страницы не запускают его автоматически. Доступна отмена.
Используется обычная ссылка в новой вкладке, как у сводки нарушений; имя файла
задаётся серверным Content-Disposition. Файл скачивается без загрузки всей книги
в память JavaScript и поддерживает возобновление через HTTP Range.

На больших периодах книга может содержать несколько листов с теми же пятью
столбцами и отдельным итогом на каждом листе. Backend должен поддерживать
новый API; при установке обновляются код сервера и готовая сборка интерфейса.
